# 智能文案与视觉素材协同创作平台

该项目提供一个基于 Vue 3 + Vite 的前端原型，覆盖智能文案创作、视觉素材生成、协作分享、跨平台广告投放以及数据分析优化五大功能模块。

## 主要特性
- 登录窗口进入主控制台，左侧导航 + 主内容 + Flat UI 布局
- 每个模块独立，包含图表、进度条、互动按钮与弹窗提示
- 使用 Vue Router 实现模块切换，主界面统一弹窗管理

## 本地运行
1. 安装依赖：`npm install`
2. 启动开发服务器：`npm run dev`
3. 生产构建：`npm run build`

> 若所在网络无法访问 `@vitejs/plugin-vue`，可配置镜像源或离线安装相关依赖。
