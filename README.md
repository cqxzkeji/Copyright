# Hazardous Waste Management System

A single-page Vue 3 application scaffolded with Vite for managing hazardous waste operations, including registration, transport tracking, storage monitoring, compliance reporting, and analytics.

## Getting Started

1. **Install dependencies**
   ```bash
   npm install
   ```
2. **Start the development server**
   ```bash
   npm run dev
   ```
3. **Create a production build**
   ```bash
   npm run build
   ```

## Project Structure

- `src/App.vue` – Shell layout with sidebar navigation.
- `src/router/index.js` – Route definitions for each module.
- `src/views/` – Feature pages such as Login, Dashboard, Waste Registration, Transport Management, Storage Management, Compliance reports, and Analytics.
- `src/style.css` – Shared styling and layout helpers.
